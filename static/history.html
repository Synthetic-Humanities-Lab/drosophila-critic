THE COMPARISON

Lead-in A contains six seconds of the synthetic recording. Lead-in B rearranges the same three two-second blocks. They have identical duration, sample distribution and total injected stimulation. Both are followed by exactly the same two-second passage, starting at exactly the same time.

For each lead-in we also run a quiet continuation, omitting the passage. This distinguishes an aftereffect from a change in how the passage is received. We repeat the four conditions with gaps of zero, half a second and two seconds.

FUNCTIONAL IMPLICATION

READING / an affective interpretation

This rule-based interpretation receives only the measured contrast summary and gap lengths. It receives no poem text, waveform or performer identity. A history-dependent neural response would support a claim about how the modeled encounter unfolds, without identifying a subjective feeling.

Method and evidence

The quiet continuations estimate what each history would produce without the passage. The difference of probe increments tests non-additivity at the selected population readout. It does not locate a biological mechanism. Immediate pre-passage drive also differs between histories; any effect could come from ordinary membrane/spike dynamics or recurrence.

Within each gap the model starts identically and encounters the passage at the same absolute time. Across different gaps, absolute timing changes, so a delay trend would be descriptive rather than a fitted memory timescale. No learning or weight changes occur.
